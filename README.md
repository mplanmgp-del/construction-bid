# 철거·공사 입찰공고 시스템

나라장터 공고·첨부파일·공개 개찰결과를 조회하고, 회원별 업체 소재지와 관심공고·투찰 준비 기록을 관리하는 React / TypeScript / Vite 앱입니다. API 호출은 Vercel 서버 함수에서 처리하고 회원 데이터는 Supabase에 저장합니다.

- 서비스: https://construction-bid-nine.vercel.app
- 비공개 저장소: https://github.com/mplanmgp-del/construction-bid
- Supabase 프로젝트: `zjmhmyzgsmglrictwqtd`

## 구현된 기능

- **나라장터 실제 공고**: 공사·용역 업무, 입찰 개시일 범위, 공고명으로 조회합니다. 최대 31일의 개시 기간에 대해 이전 90일 게시 자료까지 검색하고 전체 결과를 30건씩 표시합니다. 공고명 입력 후 조회하며 빈 검색어로 접속했을 때 자동 전체 조회하지 않습니다.
- **상세 검색**: 불러온 공고를 대상으로 공고명·번호·기관, 분야, 제외어, 현장지역, 면허, 상태, 계약방법, 추정가격, 제출 마감일을 검색하고 정렬합니다. 원본 전체 건수와 불러온 건수를 구분합니다.
- **회원별 지역 필터**: 등록한 본점 소재지와 공고의 참가 가능 지역을 비교합니다. 현장 위치는 별도로 표시합니다. 지역 자료가 누락되거나 불완전하거나 별도 조건이 있으면 `확인 필요`로 남깁니다. 지역 일치는 전체 참가자격을 확정하지 않습니다.
- **추정가격**: 기초금액으로 대체하지 않으며 미제공은 `미제공`으로 표시합니다. 금액 입력·표시·CSV는 세 자리마다 쉼표를 적용합니다.
- **상세·첨부파일**: 공고 일반, 일정, 지역·면허 조건, 추정가격·기초금액 세부 등 12개 구역을 확인하고 나라장터 HTTPS 원본 첨부파일을 새 창에서 엽니다. PC·모바일 전체 상세 페이지와 항목 검색을 지원합니다. 상세 조회로 확인한 조건은 저장된 관심공고에도 반영합니다.
- **연관 정보**: 공고 상세의 `연관 정보 불러오기`로 연결된 계약, 공개 진행 이력, 공고·수요기관 정보를 별도로 조회합니다. 조회 실패와 공개 내역 없음을 구분하며, 내역이 없는 것을 미계약·미진행으로 판정하지 않습니다. 기본 공고의 추정가격과 지역 판단을 연관 자료로 대체하지 않습니다.
- **인쇄용 PDF**: 상세의 인쇄 아이콘·`인쇄용 문서`에서 미제공·빈 이력·안내 주석을 제거한 A4 문서를 생성합니다. 실제 0원과 계산 근거는 유지하며 PDF 다운로드·인쇄를 지원합니다. [출력 기준과 사용 방법](docs/notice-printing.md)
- **회원 계정**: 이메일 가입·로그인, 비밀번호 재설정, 업체·담당자·면허 정보를 지원합니다. 회원 데이터는 본인만 읽고 수정하도록 RLS를 적용합니다.
- **관심공고와 준비 기록**: 공고를 저장한 시점의 자료도 보관하므로 현재 조회 기간 밖의 공고를 다시 볼 수 있습니다. 준비 상태·메모를 작성하면 관심공고에도 저장됩니다. 저장 실패, 재시도, 동시 수정 충돌, 브라우저 임시저장 복구를 처리합니다.
- **공개 개찰·낙찰 결과**: 기본으로 오늘의 결과를 조회하며 기간을 최대 7일까지 선택할 수 있습니다. 공고번호·업체명·사업자번호 검색은 불러온 결과에 적용합니다. 조회 건수는 공고 수가 아닌 **업체별 결과 행 수**입니다. 공개된 순위·투찰금액·투찰률·낙찰업체·낙찰금액을 표시합니다.
- **엑셀·CSV**: 현재 불러온 자료 중 필터에 맞는 목록 전체를 다운로드합니다. XLSX에는 제목·표 서식·고정행·자동필터·숫자형 금액을 적용합니다. CSV의 외부 텍스트는 엑셀 수식으로 실행되지 않도록 처리합니다.
- **투찰 도우미**: `/#bid-helper`에서 제공받은 「나라장터 투찰 도우미.xlsx」의 예상 투찰금액 계산·개찰결과 분석·29개 입찰 용어 사전을 사용합니다. 기초금액, 확인한 A값, 낙찰하한율, 가정 공고 사정률과 목표 투찰률(A)을 입력하면 A값 조정 투찰금액, 원 미만 올림한 하한가, 단순·A값 투찰률, 업체·공고 사정률을 계산합니다. 공고 상세의 `투찰 도우미로 계산`은 해당 차수에 공개된 기초금액·하한율·예가 범위를 전달하며, 추정가격이나 보험료 단순 합계를 기초금액·확정 A값으로 대신하지 않습니다. 복수 기초금액은 직접 확인해 입력합니다. 입력값은 같은 브라우저 탭에서 임시 보관하며, 순공사원가 98%와 최종 적격·낙찰 여부는 판정하지 않습니다.
- **모바일**: 공고 카드, 상세검색 패널, 공고 상세 및 회원 관리 화면을 지원합니다.

나라장터에 입찰서를 자동 제출하거나 비공개 접수증을 조회하는 기능은 포함하지 않습니다. `제출완료(직접확인)`은 사용자가 나라장터 접수 여부를 확인한 뒤 남기는 자체 관리 기록입니다. 공개 결과가 검색되지 않는다고 미제출·탈락을 의미하지 않습니다.

## 조회 범위와 갱신

공고 검색은 조건별 전체 결과를 브라우저와 Vercel Runtime Cache에 보관합니다. 5분 이내 결과는 재사용하며 24시간 이내 이전 결과는 조회 시각과 함께 먼저 표시합니다. 오래된 자료는 일반 요청으로 배경 갱신하며, 자동 강제 갱신과 5분 반복 조회는 하지 않습니다. 직접 새로고침이 실패해도 같은 조건의 유효한 전체 결과는 유지합니다. 공공데이터 한도 오류가 나면 해당 API 서비스의 추가 호출을 30분간 억제합니다. 이는 재시도 간격이며 공급자의 한도 복구 시각을 보장하지 않습니다. 브라우저가 닫힌 동안의 상시 수집·알림 서비스는 구현하지 않았습니다.

지역 자료는 조회 기간별 최대 5페이지, 페이지당 999행까지 수집합니다. 한도를 넘어 불완전한 지역 목록은 자동 제외 근거로 사용하지 않으며 경고와 `확인 필요`로 표시합니다. 기간을 줄이거나 공고 상세에서 개별 조건을 다시 확인할 수 있습니다. 면허 상세 자료는 공고 상세 조회 시 보완되므로 목록에서 아직 확보하지 못한 면허는 검색에 포함되지 않을 수 있습니다.

관심공고의 저장 자료는 해당 시점의 사본입니다. 최신 조회 자료가 있으면 우선 표시하지만, 정정·취소와 최종 참가조건은 나라장터 원문에서도 확인해야 합니다.

## 로컬 실행

Node.js 22.12 이상에서 실행합니다.

```powershell
npm ci
Copy-Item .env.example .env.local
```

`.env.local`에 다음 값을 입력합니다.

| 변수 | 용도 |
| --- | --- |
| `G2B_SERVICE_KEY` | 공공데이터포털에서 승인받은 나라장터 인증키. 서버에서만 사용합니다. |
| `VITE_SUPABASE_URL` | 이 앱의 Supabase 프로젝트 URL |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Supabase 공개 키. 브라우저에서 사용하며 데이터 접근은 RLS로 제한합니다. |

`G2B_SERVICE_KEY`에는 `VITE_` 접두사를 붙이지 않습니다. Supabase 관리자 키나 `service_role` 키는 브라우저 변수에 넣지 않습니다. `.env.local`과 `.vercel/`은 Git에서 제외합니다.

```powershell
npm run dev
```

로컬 주소는 http://127.0.0.1:5281 입니다. Vite 개발 서버에 실제 `/api` 조회 처리도 연결되어 있습니다. 포트가 사용 중이면 기존 서비스를 확인하거나 `npx vite --host 127.0.0.1 --port 5282 --strictPort`처럼 다른 포트를 명시하세요. `npm run preview`는 정적 빌드 확인용이며 로컬 API 서버를 제공하지 않습니다.

## Supabase 구성

1. 대상 프로젝트의 SQL Editor에서 [`supabase/member-workspaces.sql`](supabase/member-workspaces.sql)을 적용합니다. `bid_member_workspaces` 테이블, 본인 전용 RLS, JSON 소유자 검사, 서버 발급 수정 시각 트리거를 구성합니다. 다른 프로젝트 DB에 적용하지 않습니다.
2. Authentication에서 이메일 로그인을 사용하고 Site URL과 허용 Redirect URL을 서비스 주소 및 필요한 로컬 개발 주소로 설정합니다. 인증·비밀번호 재설정은 현재 앱 주소로 돌아옵니다.
3. 일반 사용자의 가입 확인·비밀번호 재설정 메일을 운영하려면 **사용자 지정 SMTP 발송 설정이 필요합니다**. 현재 공개 회원가입용 SMTP는 미설정이며, 우선 테스트 배포를 진행한 상태입니다. 기본 발송 제한이 있어 조직 외 이메일로의 가입 성공을 보장하지 않습니다.

회원별로 하나의 JSON 작업공간에 업체 정보, 관심공고 ID, 공고 사본, 필터 설정, 준비 기록을 저장합니다. 수정 시각을 비교하여 다른 기기에서 변경한 자료를 조용히 덮어쓰지 않도록 합니다. 저장 충돌 시 안내에 따라 미저장 내용을 내려받은 뒤 서버 자료를 다시 불러올 수 있습니다. 예시 업체 자료를 실제 회원 계정으로 자동 가져오지 않습니다.

## 관리자와 메뉴 잠금

[`supabase/menu-access.sql`](supabase/menu-access.sql)을 같은 프로젝트에 적용하면 메뉴 설정 4개와 관리자 권한 테이블이 추가됩니다. 처음에는 `MY입찰관리`만 잠깁니다. 설정을 다시 적용해도 기존 잠금 상태를 초기화하지 않습니다.

관리자 권한은 프로젝트 소유자가 확인한 기존 회원의 Auth 사용자 ID를 `bid_admin_users.user_id`에 등록해서 부여합니다. 이메일·회원 프로필·브라우저 저장값으로 권한을 판정하지 않으며 일반 회원이 이 테이블을 수정할 수 없습니다. 앱에 관리자 비밀번호나 관리자용 비밀 키를 넣지 않습니다.

관리자는 로그인 후 상단 `관리자` 메뉴 또는 `/#admin`에서 메뉴별 잠금과 안내 문구를 저장합니다. 설정은 전체 사용자에게 공통으로 적용되며, 열린 화면도 최대 30초 안에 다시 확인합니다. 관리자에게는 잠긴 메뉴 열람을 허용합니다. `/#account`는 잠금과 관계없이 로그인·로그아웃·비밀번호 복구를 위해 열려 있습니다.

메뉴를 잠그면 해당 화면 진입을 막습니다. MY입찰관리 업체 조회 API와 입찰공고 API에도 서버 검사를 적용합니다. 서버는 요청마다 잠금 여부를 확인하고, 잠긴 경로는 검증된 관리자 세션만 허용합니다. 권한 판정을 우회하는 공개 CDN 응답 캐시는 사용하지 않으며 나라장터 자료의 내부 캐시는 유지합니다. MY입찰관리를 잠근 동안에는 같은 경로를 사용하는 자동 이력 수집도 대기합니다. 기존에 수집한 자료는 유지합니다.

## API 구성

| 경로 | 내용 |
| --- | --- |
| `GET /api/notices` | `type`, `from`, `to`, 선택 `keyword`, `page`, `pageSize`로 공고·지역 자료 조회 |
| `GET /api/detail` | `number`, `revision`, `type`으로 공고·금액·지역·면허 전체 상세 조회 |
| `GET /api/related` | `number`, `revision`, `type`으로 해당 공고에 연결된 계약·공개 진행 이력·기관 정보 조회 |
| `GET /api/results` | `type`, `from`, `to`, `page`, `pageSize`로 공개 업체별 개찰결과 조회 |

API 키가 없거나 제공기관이 실패하면 오류를 표시하며 예시 데이터로 자동 대체하지 않습니다. 공식 서비스는 [입찰공고정보서비스](https://www.data.go.kr/data/15129394/openapi.do), 나라장터 공공데이터개방표준서비스, [계약정보서비스](https://www.data.go.kr/data/15129427/openapi.do), [계약과정통합공개서비스](https://www.data.go.kr/data/15129459/openapi.do), [사용자정보 서비스](https://www.data.go.kr/data/15129466/openapi.do)를 사용합니다. 사용자정보는 현재 `UsrInfoService02` 명세를 따릅니다. 공개 API 이용 한도와 원본 자료 제공 시점의 영향을 받습니다.

[공공조달통계정보서비스](https://www.data.go.kr/data/15129412/openapi.do)는 기관·업체·기간 단위의 집계용입니다. 개별 공고의 계약금액·낙찰률이나 누락 항목을 보충하는 데이터로 사용하지 않습니다.

## 예시 체험 모드

헤더의 `실제 나라장터` 선택을 `예시 체험`으로 바꾸면 기존 디자인 테스트를 사용할 수 있습니다. 공고 40건과 업체 3곳은 모두 예시입니다. 업체 정보·관심공고는 기존 브라우저 저장소에 유지하며 실제 계정 데이터와 구분합니다.

예시 모드의 일정 계산은 2026-10-12를 기준으로 고정합니다. 첨부파일은 실제 제출용 문서가 아닌 테스트용 TXT이며, 실제 모드에서는 나라장터 원본 링크를 사용합니다. 기존 시안·스크린샷·내보내기 파일은 로컬 `outputs/`에 보존되며 Git 배포에는 포함하지 않습니다.

테스트에는 지역 판정, 금액·CSV/XLSX 처리, API 요청·정규화·지역 자료 완결성, 회원 저장·복구·충돌 처리 등이 포함됩니다. [`supabase/tests/member_workspaces_rls.sql`](supabase/tests/member_workspaces_rls.sql)은 pgTAP이 준비된 로컬·테스트 DB에서 실행하는 별도 권한 검증이며, 일반 `npm test`에는 포함되지 않습니다. 검증 중 만든 사용자와 행은 트랜잭션을 롤백합니다.

Vercel은 `vercel.json`에 따라 `npm run build`를 실행하고 `dist`와 `api/*.ts` 함수를 배포합니다. Vercel 환경변수에도 위 3개 값을 설정해야 하며, `VITE_` 값 변경 후에는 다시 빌드·배포합니다. 별도의 GitHub Actions는 `main` 푸시와 PR에서 설치·테스트·빌드를 확인합니다. 빌드 성공은 실제 API 키 승인, 회원 이메일 발송, DB 권한 검증을 대신하지 않습니다.

설계 및 개발계획은 `docs/superpowers/`에 있습니다.
