# 철거·공사 입찰공고 테스트 시스템

회원별 업체 정보에 따른 지역 자동필터를 체험하는 디자인 프로토타입입니다. 실제 인증·나라장터 API 연결은 아직 포함하지 않았으며 공고 40건, 업체 3곳은 모두 예시입니다.

## 실행

Node.js 22.12 이상이 필요합니다. 이 폴더에서 실행합니다.

```powershell
npm install
npm run dev
```

접속 주소: http://127.0.0.1:5281

포트가 이미 사용 중이면 다른 서비스를 종료하거나 `npx vite --host 127.0.0.1 --port 5282 --strictPort`처럼 다른 포트를 명시하세요. 기본 실행은 포트를 임의 변경하지 않습니다.

## 체험할 기능

- 입찰공고: 작업분야, 검색어/제외어, 현장지역, 요구면허, 상태, 계약방법, 추정가격, 마감일 검색; 정렬; 페이지 이동; 검색조건 접기.
- 지역 자동필터: 기본 활성화. 지역 일치·확인 필요·제외 공고를 각각 확인할 수 있습니다. 현장 위치와 참가 가능 지역을 따로 표시합니다.
- 내 정보: 업체의 본점 소재지, 상세주소, 담당자, 이메일, 보유면허 편집.
- 헤더 테스트 업체 전환: 서울·경기·부산의 예시 업체를 전환하면 관심공고와 지역조건을 각각 확인할 수 있습니다.
- 관심공고: 별표 저장과 해제. 업체별로 브라우저에 저장됩니다.
- 상세 패널: 기본정보, 일정, 참가조건, 실제 다운로드 가능한 예시 텍스트 파일.
- 현재 목록 CSV 다운로드, 모바일 공고 카드와 상세검색 패널.

회사 프로필과 관심공고는 이 브라우저에만 저장됩니다. 실제 회원계정이나 다른 기기와의 동기화가 아닙니다. 시안의 일정 계산은 2026-10-12를 기준으로 고정해 체험 결과를 일관되게 유지합니다.
