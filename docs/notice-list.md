# 공고 목록 표시

- 공고 구분·종류·번호/차수를 공고명 위에 표시하고 검색어를 안전한 텍스트 강조로 표시한다.
- 수요기관은 dminsttNm이며 공고기관으로 대신 채우지 않는다.
- 상태 / 수요기관 / 1순위 업체 / 낙찰업체 / 추정가격 순서. 모바일에서는 같은 행을 카드로 재배치한다.
- 30건씩 표시하고 기존 10페이지 단위 이동을 유지한다. 체크한 공고가 있으면 현재 필터에 해당하는 선택 공고만 기존 CSV/엑셀로 내보낸다.
- 목록의 건수는 불러온 데이터 안에서 필터링한 수다. 나라장터 원본 조회 조건의 totalCount와 구분한다. 장기간 DB 수집/전체검색은 이번 변경에 포함하지 않는다.

## 공개 결과

/api/result-summary는 승인된 공공데이터개방표준서비스 getDataSetOpnStdScsbidInfo를 사용한다. 공식 명세에는 공고번호 조회 조건이 없어 개찰 예정 시각의 1분 범위를 조회하고, 업무/공고번호/차수를 정확히 일치시킨다.

opengRank=1의 업체와 fnlSucsfCorpNm(또는 sucsfYn=Y의 업체)를 구분한다. 첫 순위가 최종 낙찰업체라고 추정하지 않는다. 개찰완료는 실제 결과 응답에서만 표시한다. 마감만 확인되면 마감으로 표시한다.

요청당 최대 10페이지 x 999행, 30초 이내로 조회한다. 완전하지 않은 결과와 실패를 안내하며 없는 업체는 -로 표시한다. 화면은 현재 페이지의 이미 개찰 시각이 지난 공고만 동시 2건으로 조회한다. 서버의 같은 시각 조회와 결과 요약은 5분간 캐시한다. 예정 개찰 시각이 실제와 달라진 공고는 해당 시각 조회로 연결되지 않을 수 있으며 상세 공개 결과 조회로 재확인할 수 있다.

공식 명세 확인: https://www.data.go.kr/data/15058815/openapi.do
실제 검증: R26BK01748781-000 공사 / 2026-10-07 12:00 조회에서 개찰완료, 1순위 (주)거하건설. 최종낙찰명은 비어 있으므로 - 유지.

지역 자동필터는 접속·새로고침·계정 전환 시 OFF로 시작합니다. 이전에 저장된 ON 설정을 자동 복원하지 않으며, 직접 켠 설정은 현재 방문 중 화면을 이동할 때 유지합니다. 조건 초기화는 OFF로 돌아갑니다.

원본 조회 기본 업무는 공사·용역 통합입니다. 업무별 100건씩 같은 페이지를 조회하고 합계와 추가 페이지 여부를 통합합니다. 한 업무라도 실패하면 전체 조회 실패를 표시해 불완전한 합계를 숨기지 않습니다. 게시일 2026-10-07~13, 철거 직접 검증은 공사 30건+용역 22건=52건입니다. 비교 사이트의 62건은 게시일이 아닌 입찰 개시일 2026-10-07~13 조건이며, 게시일 2026-09-28인 R26BK01745816과 2026-10-01인 R26BK01752295도 포함되어 동일 조건의 결과가 아닙니다.

## 입찰 개시일 검색 (2026-10-13)

- 기본 검색은 bidBeginDt(입찰 개시일시) 기준. UI의 큰 검색창도 현재 메모리 목록만 필터링하지 않고 전체 검색을 실행한다.
- 공식 1.2 문서에서 PPSSrch의 inqryDiv=1은 게시일, 2는 개찰일이다. 2를 개시일로 오인하지 않는다. 공식 출처: https://www.data.go.kr/data/15129394/openapi.do
- API에 개시일 직접 조회가 없어, 선택 기간 시작 90일 전부터 종료일까지 게시된 자료를 31일 구간으로 나누어 자동 조회하고 KST 개시일 범위로 필터링한다. 이보다 오래 전에 게시된 공고는 범위 밖이며 UI와 결과 설명에 조회 범위를 명시한다.
- 공사/용역 전체 구간을 동시 2개씩 조회한다. 구간마다 원본의 모든 페이지(999행, 최대 30페이지, 40초 예산)를 자동으로 읽는다. 구간 실패/누락/중복/조회 중 total 변경이면 전체 검색 실패로 처리한다. 일부 수집 결과를 전체 건수로 표시하지 않는다.
- 추가 불러오기 버튼 제거. 결과 전체가 준비된 다음 30건씩 화면 페이지를 나눈다. CSV/엑셀도 선택이 없으면 전체 검색 결과를 내보낸다.
- 데이터 갱신에 따라 건수는 변한다. 로컬 2026-10-13 10:54 검증: 10/7~13 개시일, 철거, 공사·용역 65건. R26BK01745816(9/28 게시), R26BK01752295(10/1 게시)가 포함됨.
- 90일 이전까지의 게시 자료를 검색하는 제한이 있으므로 전 기간 DB 색인과 동일하다고 설명하지 않는다.
