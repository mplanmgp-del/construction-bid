# 공고 상세 인쇄 문서

공고 상세 상단의 인쇄 아이콘 또는 `인쇄용 문서` 버튼으로 문서를 생성한다. 독립 상세 페이지와 공고 목록의 전체 상세 패널에서 같은 인쇄 기능을 제공한다.

## 문서 구성

공고명·공고번호, 추정가격·일정·기관 요약, 값이 있는 상세 항목, 실제 관련 계약·기관 레코드, 첨부파일명을 A4 PDF로 구성한다. 한글 글꼴을 포함하므로 텍스트를 선택·검색할 수 있다. 일반 웹페이지 인쇄 대신 PDF 자체를 출력해 브라우저의 날짜·문서 제목·사이트 주소가 여백에 추가되지 않는다. 바닥글에는 페이지 번호만 표시한다.

- null·빈 문자열·미제공 표시값을 제외하고, 비어 있는 구역과 레코드도 제거한다.
- 공개 내역이 없는 계약·변경·삭제 이력 구역은 제목과 안내문까지 제외한다.
- 일반 화면의 조회 안내·미제공 주석·원문 확인 링크는 문서에 넣지 않는다.
- 실제 0원·0%·없음·아니오 값은 유지한다. 기초금액을 추정가격으로 대체하지 않는다.
- 계산값은 계산값이라는 이름과 보험료·관리비 7개 항목의 합산 근거를 유지한다.
- 상세 검색·접기 상태에 관계없이 조회된 전체 데이터로 구성한다.
- 공고번호·차수·업무 구분이 다른 자료는 혼합하지 않는다.

## 생성과 출력

인쇄창을 열 때 아직 연관 정보를 조회하지 않았다면 연관 API를 한 번 조회한다. 일부 조회가 실패하면 인쇄창에 알리고 확인된 데이터로 PDF를 만든다. 이 상태 안내는 PDF에 인쇄하지 않는다.

`PDF 다운로드`는 완성된 PDF를 저장한다. 데스크톱의 `PDF 인쇄`는 로드된 PDF 프레임의 인쇄창을 호출한다. 모바일 또는 프레임이 아직 준비되지 않은 환경은 PDF 뷰어를 열어 사용자가 인쇄를 선택하게 한다. 항상 `PDF 새 창으로 열기` 링크도 제공한다. 실제 프린터 선택과 출력 확인은 브라우저·운영체제에서 진행한다.

인쇄창을 닫거나 다른 공고로 이동하면 진행 중 조회를 취소하고 늦게 도착한 결과를 버린다. 중첩 상세 패널에서도 Escape 및 키보드 포커스를 처리한다.

PDF 모듈과 한글 글꼴은 인쇄 기능을 처음 사용할 때 로드한다. 문서는 브라우저 안에서 생성하며 외부 PDF 변환 서비스에 공고나 회원 자료를 보내지 않는다. 글꼴 출처와 라이선스는 [글꼴 문서](pdf-font-license.md)에 있다.

## 검증 기준

인쇄 모델 테스트는 미제공 제거·정상 0과 없음 보존·빈 이력 제거·부분 성공·자료 식별자 일치·계산 근거·파일명 안전성을 검증한다. 실제 철거공고 `R26BK01756915-000`으로 추정가격 50,709,091원, 보험료·관리비 합계 3,251,825원, 첨부서류 2개가 포함된 PDF를 생성해 전 페이지의 한글과 표 배치를 확인한다. 빈 계약 변경·삭제 이력 및 화면 안내문은 PDF에 포함되지 않는다. 산출물과 검수 기록은 로컬 `outputs/print-detail/`에 저장한다.
