# 철거·공사 입찰공고 디자인 테스트 시스템

2026-10-12 사용자가 GUI v4를 기준으로 디자인을 확장한 테스트 시스템 개발을 요청했다. 이번 범위는 로컬에서 체험하는 프런트엔드 프로토타입이다.

## 승인된 화면과 행동

- 기존 흰색·코발트·남색 GUI의 정보구조를 유지하고 데스크톱 및 모바일에서 사용 가능하게 구현한다.
- 입찰공고, 관심공고, 내 정보 세 화면. 예시 회원/업체 전환을 제공한다. 실제 인증과 공공데이터 API 연결은 다음 단계다.
- 업체명, 본점 소재지(시·도/시·군·구), 주소, 보유면허, 담당자 정보 수정. 회원별 업체정보와 관심공고를 브라우저에 따로 보존한다.
- 공사 현장 위치와 참가 가능 지역을 구분한다. 자동 지역필터는 기본 활성화하며, 불일치 공고를 숨기고 불명확한 공고는 확인 필요로 남긴다. 제외 공고 보기 및 필터 해제를 제공한다.
- 전국·복수지역·시군구 제한을 처리한다. 누락된 업체 소재지, 빈 지역조건, 공동수급 등 복잡한 조건을 전국 또는 최종 참가가능으로 단정하지 않는다.
- 금액 열, 범위 검색, 정렬은 추정가격을 사용한다. 미제공 금액은 0원으로 취급하지 않으며 금액조건이 있을 때는 해당 검색에서 제외한다.
- 카테고리, 검색어/제외어, 공고 구분, 공사 위치, 면허, 상태, 계약방법, 마감일 필터와 정렬·페이지 이동이 실제로 동작한다.
- 접기·펼치기, 필터 요약칩, 초기화, 검색결과 없음 상태를 제공한다.
- 공고 상세 패널은 기본정보·참가조건·일정·예시 첨부서류를 보여준다. 예시 파일 다운로드는 실제 예시 텍스트 파일을 생성하며 실제 공고 원문으로 가장하지 않는다.
- 시안/예시 데이터임을 명시한다. 날짜는 2026-10-12를 예시 기준일로 고정한다.

## 구조

React + TypeScript + Vite. `src/types.ts` 공유 계약, `src/data.ts` 예시 자료, `src/domain.ts` 지역판정/검색/정렬, `src/storage.ts` 회원별 저장, UI 컴포넌트와 반응형 CSS를 분리한다. 로컬 포트는 5281로 정하고 엄격한 포트 바인딩을 사용한다.

## 검증

지역 판정과 추정가격 필터에 의미 있는 단위 테스트를 실행한다. 빌드·타입검사 후 브라우저에서 필터, 업체전환, 저장·재열기, 상세패널, 관심공고, 모바일 화면 및 콘솔 오류를 확인한다.
