# 공고 연관 API 신청 및 연결

확인일: 2026-10-12

## 활용신청 결과

공공데이터포털의 로그인된 활용신청 현황에서 신규 4개 서비스의 승인 상태를 확인했다. 모두 개발계정이며 신청일은 2026-10-12, 만료예정일은 2028-10-12다.

| 서비스 | 신청 상태 | 공고 상세 연결 |
| --- | --- | --- |
| [계약정보서비스](https://www.data.go.kr/data/15129427/openapi.do) | 승인, 21개 상세 기능 | 계약금액·기간·업체·기관, 변경·삭제 이력 |
| [계약과정통합공개서비스](https://www.data.go.kr/data/15129459/openapi.do) | 승인, 4개 상세 기능 | 발주계획·사전규격·조달요청·공개 낙찰·연결 계약 |
| [사용자정보 서비스](https://www.data.go.kr/data/15129466/openapi.do) | 승인, 5개 상세 기능 | 공고·수요기관의 코드·주소·대표전화·등록정보 |
| [공공조달통계정보서비스](https://www.data.go.kr/data/15129412/openapi.do) | 승인, 14개 상세 기능 | 기관·업체·기간별 집계용이므로 개별 공고 상세에는 사용하지 않음 |

기존 입찰공고정보서비스 및 공공데이터개방표준서비스 승인도 유지되어 있다. 신규 개발 기본 트래픽은 상세 기능별 일일 1,000회이며, 사용자정보 서비스는 10,000회다. 실제 할당량은 포털 계정 설정을 기준으로 한다. 신청 화면과 승인 증거는 로컬 `outputs/api-application-status.md` 및 `outputs/api-applications/approved-list.jpg`에 있다. 인증키는 서버 환경변수에서만 사용한다.

## 사용 방법

실제 공고의 전체 상세에서 `계약·진행 이력·기관` 바로가기를 누른 뒤 `연관 정보 불러오기`를 누른다. 독립 페이지와 목록의 상세 패널에서 동일하게 사용할 수 있다. 최초 상세 열기나 바로가기 이동만으로 추가 API를 호출하지 않는다.

`GET /api/related?number=공고번호&revision=차수&type=공사`가 5개 구역을 반환한다. 공사·용역을 지원한다.

- 발주·사전규격·조달 과정
- 공개 낙찰 정보
- 관련 계약
- 공고·수요 기관 등록정보
- 계약 변경·삭제 이력

추정가격과 기초금액은 기존 상세에서 각각 유지한다. 연관 계약금액으로 추정가격을 대체하지 않는다. 모든 금액에는 세 자리 쉼표를 적용한다.

## 연결 및 조회 범위

- 공고번호·차수·업무 구분을 대조한다. 차수 없는 계약 응답은 정확한 공고 차수의 통합과정 응답에 있는 계약번호와 교차검증한다.
- 기관 코드는 해당 공고의 공식 응답에서 가져온다. 사용자정보는 현행 `UsrInfoService02`를 사용하며, 변경일 기준 최근 365일씩 최대 3개 구간에서 조회한다. 미조회는 기관 미등록을 의미하지 않는다. 조회 기간을 카드에 표시한다.
- 연결 계약 최대 3개의 변경·삭제 이력을 조회하며, 각 목록은 최대 100건이다. 초과나 일부 실패는 확인사항으로 표시한다.
- 전체 조회는 30초 범위, 개별 요청은 최대 12초로 제한한다. 기존 서버의 5분 캐시·동시 요청 중복 방지·캐시 개수 제한을 재사용한다.
- 정상 0건과 API 오류·불명확한 연결을 구분한다. 일부 서비스가 실패해도 성공한 구역은 표시한다. 공개 내역이 없다는 이유로 미계약·절차 미진행이라고 판정하지 않는다.
- 기관 정보는 공개된 업무 정보다. 회원의 개인 투찰 접수 현황이나 실제 제출을 이 API로 대신하지 않는다.

## 검증

전체 자동 테스트 156개, 타입 검사 및 프로덕션 빌드가 통과했다. 공고 차수 불일치, 공개 목록의 열 위치, 계약금액·지분율, 빈 결과와 실패 구분, 부분 실패, 기관 조회 기간 확장, 잘못된 요청을 검증했다.

PC 1440px와 모바일 390px·320px에서 실제 데이터를 표시하고 가로 넘침, 구역 이동, 버튼 크기, 최초 불필요한 API 호출, 콘솔 오류를 확인했다. 배포 후의 실행 결과와 화면 증거는 로컬 `outputs/related-detail/`에 보관한다.
