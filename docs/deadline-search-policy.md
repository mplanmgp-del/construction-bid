# 제출마감일 검색 및 공고 알람

- 일반 검색·맞춤 조회의 날짜 기준은 `deadline`(입찰서 제출마감)이다. 기본은 한국 날짜 오늘의 이전 6개월부터 이후 6개월까지다.
- 전후 1·3·6개월 버튼은 양쪽에 같은 달력 개월 수를 적용하고 즉시 조회한다. 월말은 해당 월의 마지막 날로 보정한다. 시작·종료 날짜를 모두 포함하며 수동 조회 상한은 367개 날짜다.
- 화면은 `/api/notices?mode=deadline`으로 선택한 구간의 공통 색인만 읽는다. 제공기관의 게시일·개찰일 검색을 제출마감 검색으로 대신 사용하지 않는다.
- 색인 후보는 번호별 전체 차수를 조회한 뒤 최신 차수의 마감일과 상태를 다시 검사한다. 최신 변경·취소를 이전 차수로 대체하지 않는다.
- 진행중·마감 임박·예정만 현재 목록에 표시한다. 제출마감이 지났어도 개찰이 미래이면 개찰 대기로 포함한다. 취소, 개찰일 경과, 공식 개찰 완료, 제출마감 미확인 자료는 제외한다.
- 공고번호 직접 조회·이전 차수·상세·공개 결과는 기간 제한과 별개의 이력 확인 기능이다. 관심공고 및 기존 알림함 원본 기록은 보존한다.
- 자동 공고 알람은 한국 날짜 오늘 이전 7일부터 이후 7일까지의 제출마감에만 적용한다. 기존 개인 조건도 함께 적용한다. 발송 직전 현재 최신 차수·날짜·상태를 재검사한다.
- 회원별 공고·변경 버전 기록은 보존한다. 범위 밖·완료·취소 변경은 재발송하지 않으며 중복 방지 기록은 갱신한다.

## 수집과 저장

공통 색인은 회원 조건과 독립적이다. 개인 조건 변경으로 과거 원본을 다시 수집하지 않는다. 원본 페이지는 실제 제공기관 상한인 999건씩 읽고, 최대 200건의 경량 배치로 색인을 저장한 뒤 처리 위치를 기록한다. 본문·첨부파일은 저장하지 않는다. 색인과 알람은 기존 16MiB/32MiB 한도를 함께 지킨다.

공식 API는 제출마감 기간 검색을 제공하지 않으므로 최초 공통 색인을 보충할 때는 넓은 게시 구간을 확인한다. 최신 월을 먼저 읽으며 최초 수집이 끝나기 전에는 `indexCoverage.complete=false`와 남은 구간을 표시한다. 화면 조회는 이 최초 수집과 별개이며 다른 게시 기간을 직접 읽지 않는다.

이전의 조건 일치 공고만 수집한 소요 시간을 전체 공통 색인의 완료 시간으로 사용하면 안 된다. 신규·변경 자료는 독립된 커서로 10분마다 확인하고, 최초 수집도 저장한 위치에서 계속 진행한다. 제공기관 지연·호출 한도·저장 한도에 걸리면 위치를 넘기지 않고 다음 실행에서 재시도한다.
