# 내 정보로 찾기

기존 ‘내 지역 이름 포함’을 ‘내 정보로 찾기’로 변경했다. 켜면 내 정보의 시·도 지역 키워드와 저장된 공식 업종코드 중 하나가 모두 일치하는 공고를 찾는다. 지역 검색은 기존 시·도 키워드와 전국 참가 공고 포함 기준을 유지한다. 최종 입찰 참가자격을 확정하는 기능은 아니다.

- 업종코드는 여러 개 중 하나가 일치하면 되며 `0002`처럼 앞의 0도 보존한다.
- 수동 검색어·지역·업종·금액 등은 별도의 조건으로 함께 적용한다. 토글을 끄면 기존 수동 조건으로 돌아간다.
- 프로필 저장값은 변경하지 않는다. 지역이나 유효한 업종코드가 없으면 등록 안내와 비활성 토글을 표시한다.
- 코드가 미확인인 공고는 일치 결과로 표시하지 않고 서버의 확인 대기에 남긴다. 기존 자료의 추가 업종코드 재확인도 요청한다.
- 전체 결과 수·정렬·다음 페이지·자료 확인 상태에 같은 조건을 적용한다. 브라우저에서 받은 한 페이지만 다시 거르지 않는다.
- ‘이 조건으로 알림 받기’에서도 내 업체 지역·업종 비교와 수동 업종 조건을 유지한다. 기존 알림 설정을 자동으로 저장하거나 테스트 푸시를 보내지 않는다.
