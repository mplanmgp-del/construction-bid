# 입찰공고 PDF 글꼴

입찰공고 PDF는 **Nanum Gothic**의 Regular(400)·Bold(700) 원본 TTF를 포함하여 한국어를 선택·검색할 수 있는 텍스트로 출력합니다. 글꼴은 애플리케이션의 `/fonts/`에서만 불러오며 외부 글꼴 서비스에 접속하거나 공고 데이터를 전송하지 않습니다.
