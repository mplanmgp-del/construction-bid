# 나라장터 전체 상세정보 화면

## 사용 경로

- 실제 공고 목록에서 공고 선택 → `전체 상세` 탭.
- 상세 화면의 `넓은 화면으로 보기` → 독립 상세 페이지.
- 독립 페이지: `/notice-detail.html?number=R26BK01764541&revision=000&type=공사`.
- 기존 디자인 시안(`/detail-design.html`)에도 실제 전체 상세 화면 링크를 제공한다.

## 표시 원칙

사용자가 제공한 나라장터 원문을 기준으로 공고 일반, 진행 정보, 투찰 제한, 공종별 지분율, 공사 정보, 가격, 심사, 부공종, 수수료·보증금, 기관 담당자, 연관 정보, 기초금액 공개를 구성했다. 기본 구성이 12개 구역·141개 항목이며, 공종이나 기초금액 내역이 여러 건이면 항목을 추가한다. 첨부서류는 API의 실제 파일명과 나라장터 원본 링크를 사용한다.

추정가격을 상단에 강조하고 예산금액·부가세·기초금액·관급금액과 구분한다. 추정가격이 없으면 다른 금액으로 대체하지 않는다. 명시적 0과 빈값은 구분하며, 참고 이미지의 순공사원가 0원·업종평가비율 100%를 실제 공고에 대입하지 않는다.

API에 없는 계약구분·공사기간·첨부 용량 등은 `미제공`과 원문 확인 안내로 표시한다. 원문에서 한 번 관찰한 특정 공고의 값을 모든 공고에 적용하거나 서버 코드에 고정하지 않는다. 담당자 정보는 공개 API에서 반환한 업무 연락처만 사용한다.

7개 보험료·관리비가 모두 제공된 경우에만 합계를 계산한다. 이를 확정된 A값으로 일반화하지 않으며, 계산값과 적용 여부·품질관리비 적용 대상을 별도로 표시한다.

## 조회와 오류 처리

`/api/detail`이 일반 공고, 기초금액, 지역, 면허 정보를 병렬 조회한다. 각 응답은 공고번호와 차수를 정확히 대조하며, 다른 차수의 데이터를 섞지 않는다. 일반 공고가 중복되어 모호한 경우 임의의 첫 행을 선택하지 않는다. 기초금액 공개 내역이 여러 건이면 각각 분리한다.

일부 조회가 실패하면 성공한 정보는 유지하고 경고를 표시한다. API 키는 서버에만 둔다. 회원 정보·관심공고·투찰 준비 저장 구조는 변경하지 않았다.

## 화면 동작

- PC 2열 정보표, 모바일 1열 레이블/값 배치.
- 항목명·값 검색, 구역 바로가기, 개별 및 전체 접기/펼치기.
- 조회 시각·재조회·실패 안내, 원문 및 첨부 링크.
- 모바일 원문 버튼 고정, 인쇄 시 접힌 항목도 출력.
- 기존 상세 창 안에서도 컨테이너 폭에 맞춰 반응형으로 표시.

추가 승인받은 API의 계약·공개 낙찰·진행 과정·기관·계약 이력은 별도 버튼으로 불러온다. 연결 기준과 조회 범위는 [공고 연관 API 문서](related-notice-information.md)에 정리했다.

## 검증

전체 테스트 136개 및 타입 검사·빌드 통과. 공사 `R26BK01764541-000`과 용역 `R26BK01753034-000`으로 실제 API 조회를 확인했다. 단위 테스트에는 차수 불일치, 일부 조회 실패, 비밀값 오류 노출 방지, 미제공과 0의 구분, 추정가격 대체 금지, 복수 기초금액 분리 및 재조회 후 상세 탭 간 표시 일관성을 포함한다. PC 1440px와 모바일 390px·320px에서 항목 검색, 접기·구역 이동, 첨부 링크, 기존 목록의 상세 패널과 가로 넘침을 점검했다.
