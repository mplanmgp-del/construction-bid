# 지역명 키워드 필터

사용자 요청: 공고지역 필터를 모든 부분에서 지역이름 키워드로 검색하도록 변경.

## 동작

- 입찰공고 검색, 관심공고, 자동조회, 업체 소재지 자동필터에 동일한 키워드 판정을 사용한다.
- 공고명, 발주·수요기관, 현장 주소, 참가 가능 지역, 설명·조건, 첨부파일명과 API 추가 텍스트를 함께 검색한다. 첨부파일 본문을 내려받아 분석하는 기능은 포함하지 않는다.
- 시·도는 서울/서울특별시 등 기존 별칭을 함께 찾는다. 시군구·읍면동 선택은 마지막 지역명 키워드로 찾으며 여러 선택은 OR다. 같은 이름의 지역은 함께 발견될 수 있다.
- 전국 참가 공고는 모든 지역에 포함한다. 지역 근거가 없으면 미확인으로 분류하고 기존 포함 설정을 따른다.
- 업체 자동필터는 업체의 시·도 이름을 사용한다. 상세 화면의 실제 참가자격 판정은 별도로 유지한다.
- 기존 자동조회 regionBasis 저장값은 읽고 보존하지만 검색 범위를 좁히지 않는다. 화면의 기존 비교 기준 선택은 고정 안내로 대체한다.

## 수집과 저장

원본 API의 문자열을 검색용 텍스트로 보존한다. 주소 등을 우선하고, 긴 본문 전체에서 지역명을 먼저 추출하므로 본문 뒤의 지역명도 남는다. 검색용 텍스트는 최대 16,000자이며 인증정보·연락처·URL은 제외한다. 기존 저장소의 24 MiB / 전체 32 MiB 한도는 유지한다.

새 마이그레이션은 기존 색인 행의 공고명과 기관명에도 즉시 새 판정을 적용한다. 과거에 버려진 API 추가 필드는 공식 원본이 재수집될 때 보강된다. 수집 범위를 전체 원본 수집 완료로 해석하지 않는다.

## 검증

- 전체 Vitest: 117개 파일, 1,302개 통과.
- TypeScript 검사 및 운영 빌드 통과. 기존 Excel 내보내기 청크 크기 경고만 존재.
- SQL: 기존 9개 묶음 및 신규 region_name_keyword_filtering 통과. 동일 마이그레이션 두 번 적용 검증 통과.
- 운영 DB에 20261016042754_region_name_keyword_filtering.sql 적용 성공.
- 운영 검색 API에서 철거 + 서울특별시 + 미확인 제외 검색 3건 확인.
- 운영 DB에서 현장·참가 지역에 서울이 없어도 기관명이 서울지방조달청인 R26BK01749070 등이 서울 키워드로 판정되는 것을 확인.

운영 배포와 브라우저 검증 결과는 배포 후 보강한다.
