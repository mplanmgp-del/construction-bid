# 입찰 상세페이지 반응형 시안

확인 주소: `/detail-design.html`

2026-10-12 제공된 세 장의 참고 화면을 바탕으로 만든 별도 디자인 시안이다. 실제 공고 목록과 API 화면은 기존 `/`에서 이용한다. 시안은 참고 이미지의 예시 공고를 표시하며 실시간 데이터나 회원의 저장된 정보를 사용하지 않는다.

## 정보 구성

- 상단: 공고명, 공고번호, 발주기관, 추정가격, 제출 마감, 투찰하한율, 예가변동폭, 지역 및 업종.
- 일정 요약: 입찰 개시, 참가자격 등록 마감, 제출 마감, 개찰을 순서대로 표시.
- 공고 일반: 계약·낙찰방법, 기관, 공고 종류 및 적용 대상.
- 일정 및 진행정보: 담당자, PQ·실적심사, 현장설명, 공동수급협정서, 개찰 및 재입찰.
- 참가자격 및 투찰제한: 지역, 업종 코드, 지사 허용, 공동도급 및 구성원 조건.
- 가격 및 예정금액: 추정가격을 우선 표시하고 기초금액, A값, 순공사원가, 관급금액, 복수예가를 별도로 제공.
- 적격심사, 수수료 및 입찰보증금, 첨부서류 4개.

참고 화면의 빈 항목은 `미기재`로 표기한다. `0원`, `없음`, `비공개`와 구분하며 누락 값을 추정하여 채우지 않는다. 원본 사이트의 서비스 담당자 정보는 공고 담당자로 옮기지 않는다.

## 반응형 및 동작

PC에서는 상세정보와 업체 검토 도구를 두 열로 배치한다. 모바일에서는 상세정보를 한 열의 항목 카드로 전환하고, 구역 바로가기 및 하단 관심공고·나라장터 원문 버튼을 제공한다. 상세 구역은 개별 또는 일괄로 접고 펼칠 수 있다.

소재지 선택, 관심공고, 체크리스트, 메모는 현재 화면에서 체험할 수 있다. 새로고침하면 초기화되며 회원 데이터에 저장하지 않는다. 지역조건 일치는 참가자격 확정으로 표시하지 않는다. 파일명 복사와 원문 링크는 실제 동작하며, 다운로드되지 않는 가상 파일을 실제 첨부파일로 제공하지 않는다.

인쇄 시 접혀 있는 정보도 모두 표시한다. 키보드 초점, 구역 이동, 대화상자와 감소 모션 환경을 지원한다.

## 구현 파일

- `detail-design.html`: Vite의 두 번째 진입점.
- `src/design/BidDetailDesign.tsx`: 상세 시안과 화면 동작.
- `src/design/detailFixture.ts`: 참고 화면에서 옮긴 항목과 첨부파일명.
- `src/design/detailDesign.css`: PC·모바일 및 인쇄 스타일.

실제 API 필드 연결과 기존 상세 패널 교체는 이 시안의 후속 적용 단계다.
